# Office — structural grid & layer conventions

## Typical structural grid

Office buildings typically use a wider bay than residential (open-plan floor plates, movable
partition compatibility) but not necessarily as wide as a hospital's OR-driven grid.

- Typical bay: **~7.2-8.4 m** — close to the hospital typology's 7.8×8.4m (both favor large,
  reconfigurable floor plates), but no specific project drove this figure this session; treat as
  a placeholder pending a real office reference drawing (rule 71 step 2), same caveat as
  residential's grid figure.

## This tool bank's own CAD layer key (unchanged)

Same AIA-style key as every other typology. No office-specific layer extensions needed —
nothing researched this session (BHP §19/§20, ZL III classification) requires a dedicated
shielding-style layer the way hospital's lead/Faraday walls do.
