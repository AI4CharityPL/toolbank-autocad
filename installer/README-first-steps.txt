AutoCAD AI Assistant - first steps
==================================

1. Restart AutoCAD (2025 or newer).
2. At the command line, type: ACADAI
   The "AI Assistant" palette opens.
3. Go to the "Settings" tab:
   - Choose an AI provider: OpenAI, Anthropic (Claude) or Google Gemini.
   - Change the model name if you need to.
   - Paste your own API key and click "Save key".
     The key is encrypted locally (Windows DPAPI) and never leaves this computer.
4. Go back to the "Chat" tab and ask for something, for example:
   - "Count the entities per layer in this drawing."
   - "Prepare a door and window schedule."
   - You can also attach an image or a PDF with the paperclip button.

Where to get an API key:
   - OpenAI:    https://platform.openai.com/api-keys
   - Anthropic: https://console.anthropic.com/
   - Google:    https://aistudio.google.com/apikey

Requirements: AutoCAD 2025+ (Windows 64-bit) and internet access for the AI provider you choose.
