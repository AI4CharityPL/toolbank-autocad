`sample.pdf` — fixture for verifying `acad-underlays.attach_pdf_underlay`.

Generated by this bank's own already-verified `files.export_file` (format `PDF`, scope
`Extents`), never hand-crafted, never a personal document. The drawing exported was:

- a closed 300 x 100 rectangle (`draw_polyline`, `(0,0)`–`(300,0)`–`(300,100)`–`(0,100)`)
- one circle, radius 15, centred at `(30,80)` — near the top-left corner ONLY

Deliberately non-square content (rule 26 §14). **Measured after generating it:** AutoCAD's PDF
exporter fits the drawing onto a default page rather than cropping to content, so the file's
actual `/MediaBox` is a standard `612 792` (US Letter portrait, ratio 0.773) — not the drawing's
own 3:1. Still non-square, still enough to catch a width/height swap in the underlay tool (which
would read back as ~1.294 instead). `scripts/verify-pdf-underlay.py` reads the real `/MediaBox`
straight out of the file bytes at runtime rather than assuming a ratio, so this fact travels
with the fixture instead of being hardcoded somewhere it can go stale.

Regenerate with:

```python
S['geometry-2d'].call('draw_polyline', {'vertices': [
    {'x':0,'y':0}, {'x':300,'y':0}, {'x':300,'y':100}, {'x':0,'y':100}
], 'closed': True})
S['geometry-2d'].call('draw_circle', {'center': {'x':30,'y':80}, 'radius': 15})
S['files'].call('export_file', {'path': '<this file>', 'format': 'PDF', 'scope': 'Extents'})
```
